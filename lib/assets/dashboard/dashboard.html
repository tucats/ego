Settings

        
Settings are saved as browser cookies and persist across sessions.


        
Appearance

        

            

                
                
                
            

            

                Dark mode
                Use a dark color scheme for all tabs, or "Auto" to match your browser/OS setting. The Code tab always uses its own dark theme regardless of this setting.
            

        


        

            
            

                Use Text Buttons
                When selected, buttons display the text name of the function instead of only an icon.
            

        


        
Logins

        

            
            

                Remember login
                Save the API token as a browser cookie (expires after 24 hours). When enabled, you will not need to log in again after closing this tab.
            

        

        

            
            

                Use passkeys
                Allow passkey (biometric / hardware key) login and registration. Turn off to use passwords only, even if the server supports passkeys.
            

        


        
Code

        

            
            

                Format
                Reformat code before each Run/Debug, and SQL before each Submit. Remembered across sessions.
            

        

        

            
            

                Console
                Show the Console panel for running one-off statements alongside the editor. Remembered across sessions.
